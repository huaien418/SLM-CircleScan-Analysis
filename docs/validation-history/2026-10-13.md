## Interpretation boundary

This validation proves that the V2 MATLAB functions can execute their intended
software workflow on controlled synthetic data. It does not prove:

- that the camera sampling is synchronized with CircleScan;
- that image periodicity is a geometrically correct XY circle;
- that scanner response samples map one-to-one to command points;
- that a real powder bed can satisfy the configured CV, direction, or separation gates;
- that `Top1MeanDN` is a physically valid production thickness estimator.

Those claims require the planned machine experiment and independent R01-R05
re-powdering data.
