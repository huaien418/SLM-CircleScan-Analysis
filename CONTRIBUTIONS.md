# Contributions and provenance

This portfolio presents GitHub user `huaien418`'s SLM/CircleScan research analysis workflow. The research use case and experiment context belong to that work; the code and documents describe their implementation and evidence boundaries.

AI assistance was used in code development/review and in preparing this public copy, documentation, and synthetic validation. The repository is not presented as entirely unaided hand-written code. This publication records software behavior; it does not create new physical experiment evidence or claim authorship of upstream tools.

MATLAB and its runtime are MathWorks products and are not included. Hardware interfaces, vendor components, full machine-control projects, other researchers' papers, and private experiment data are excluded from this release. No new blanket license has been selected for the repository as part of this publication.
